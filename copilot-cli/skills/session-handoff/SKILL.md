# 跨会话交接

目的：下一个会话（或另一个人）不用重新读一遍代码就能接着干。

## 收尾时写

写到 `.copilot/handoff/latest.md`（覆盖）。历史归档同目录 `YYYY-MM-DD-<主题>.md`。

结构固定，不要自创：

```markdown
# 交接：<主题>
更新时间：<日期时间>

## 目标
一句话，说清这轮要达成什么。

## 已完成
- 具体做了什么，带 `文件:行号` 或 PR 号
- 只写已落地并验证过的，计划中的不算

## 未完成
- 卡在哪、试过什么、为什么没用
- 明确"下一步第一件事"是什么

## 关键结论
- 这轮学到的、下次不必再试的东西（踩的坑、被推翻的假设、第三方限制）
- 每条一行，写"因为……所以……"

## 环境与命令
- 需要特定版本、路径、环境变量、启动命令的，全部列出

## 待确认的问题
需要人拍板的事项，按优先级列。
```

## 开头时读

先读 `.copilot/handoff/latest.md`。读到就按里面的"下一步第一件事"开始，不要重新探索已经排除过的方向。

文件不存在就直接干活，不要为找不到交接文件停下来问。

## 硬约束
- 只写有证据的内容，未验证的写在"待确认"里
- 不复制大段代码，链接到 `文件:行号` 即可
- 每次覆盖 latest.md，不要把历史堆在同一个文件里
- "关键结论"是这个文件最有价值的部分，至少写 3 条，写不出来说明这轮没有沉淀
